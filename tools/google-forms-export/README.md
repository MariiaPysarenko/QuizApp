# Експорт тестів із Google Forms

Скрипт `Code.gs` зберігає Google Form у JSON-файл, який можна імпортувати в Quiz App.

## Кроки

1. Відкрийте свою форму в режимі редагування.
2. Меню ⋮ → **Редактор скриптів** (або **Розширення → Apps Script**).
3. Замініть вміст `Code.gs` кодом із цієї папки та збережіть.
4. Виберіть функцію `exportFormToJson` і натисніть **Виконати**. Під час першого запуску Google попросить дозволи на читання форми та створення файлу на Drive.
5. Відкрийте **Журнал виконання** — там буде посилання на файл `<назва форми>.quizapp.json`.
6. Завантажте файл і імпортуйте його в Quiz App.

## Що імпортується

| Тип у Google Forms | Результат |
|---|---|
| Кілька варіантів (`MULTIPLE_CHOICE`), випадний список (`LIST`) з однією правильною відповіддю | імпортується |
| Прапорці (`CHECKBOX`), текст, абзац, шкала, сітка | пропускається, причина є у звіті |
| Запитання без позначеної правильної відповіді | пропускається |
| Заголовки секцій, розриви сторінок, зображення | ігноруються |

Щоб правильні відповіді й бали потрапили в експорт, форма має бути в режимі **«Тест»**, а правильні варіанти — позначені в ключі відповідей.

Приклад результату: [`example.quizapp.json`](example.quizapp.json). З нього імпортуються 2 запитання, 2 пропускаються.
