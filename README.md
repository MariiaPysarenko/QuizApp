
# Quiz App

A web application for creating and taking online quizzes with automatic grading, attempt history, and practice based on previous mistakes.

## About the Project

Quiz App is a pet project designed to make knowledge assessment and self-study easier. It allows teachers to create quizzes and students to test their knowledge, track their progress, and review incorrectly answered questions.

## Features

- **Quiz Management** — create, edit, and delete quizzes.
- **Question Management** — add questions with multiple answer options and one correct answer.
- **Automatic Grading** — calculate quiz results automatically.
- **Attempt History** — save and review previous quiz attempts.
- **Mistake-Based Practice** — practice questions answered incorrectly in previous attempts.
- **Role-Based Access** — separate functionality for students and teachers.

## User Roles

### Student
- Take available quizzes.
- View scores and previous attempts.
- Review incorrect answers.
- Practice previously missed questions.

### Teacher
- Create and manage quizzes.
- Add questions, answer options, and correct answers.
- View results for their quizzes.
